# SmartMethods - User Management System

A simple web application for managing users with live updates.

## 🚀 Features
- Add new users (Name and Age)[cite: 2]
- Display all users in a table[cite: 2]
- Toggle user status (0 = Inactive, 1 = Active) instantly without page refresh[cite: 2]

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript[cite: 2]
- **Backend:** PHP[cite: 2]
- **Database:** MySQL[cite: 2]
- **Hosting:** InfinityFree[cite: 2]

## ⚙️ Setup & Installation
1. Create a MySQL database and import the `database.sql` file[cite: 2].
2. Update your database credentials in `api/config.php`[cite: 2].
3. Upload all project files to your hosting server (`public_html` / `htdocs`)[cite: 2].
